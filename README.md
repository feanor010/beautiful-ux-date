# 🎉 Коллекция неудобных способов ввода даты рождения

Демонстрационный проект, показывающий различные UX антипаттерны для ввода даты рождения. Каждый пример демонстрирует намеренно неудобный способ ввода даты, чтобы показать, как **не** стоит делать интерфейсы.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск dev-сервера

```bash
npm run dev
```

Приложение откроется по адресу `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

### Превью продакшен сборки

```bash
npm run preview
```

## ➕ Как добавить новый пример

Добавление нового примера неудобного UX очень просто:

### Шаг 1: Создайте компонент

Создайте новый файл в `src/components/examples/`, например `MyBadExample.tsx`:

```tsx
import './MyBadExample.css';

export const MyBadExample = () => {
  return (
    <div className="my-bad-example">
      <h3>Название вашего примера</h3>
      <p className="description">Описание того, почему это неудобно</p>
      {/* Ваш неудобный UI здесь */}
    </div>
  );
};
```

### Шаг 2: Создайте стили

Создайте файл `MyBadExample.css` в той же папке.

### Шаг 3: Экспортируйте компонент

Добавьте экспорт в `src/components/examples/index.ts`:

```tsx
export { MyBadExample } from './MyBadExample';
```

### Шаг 4: Зарегистрируйте пример

Добавьте запись в массив `examples` в `src/data/examples.ts`:

```tsx
import { MyBadExample } from '../components/examples';

export const examples: DateInputExample[] = [
  // ... существующие примеры
  {
    id: 'my-bad-example',
    title: 'Название примера',
    description: 'Краткое описание',
    component: MyBadExample,
  },
];
```

Готово! Новый пример автоматически появится в навигации.

## 🛠 Технологии

- **React 19** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик и dev-сервер
- **CSS** - стилизация

## 📝 Принципы проекта

- **Чистый код** - следуем SOLID и KISS принципам
- **Расширяемость** - легко добавлять новые примеры
- **Типобезопасность** - полная поддержка TypeScript
- **Современный UI** - красивый интерфейс для демонстрации плохого UX

## 🎯 Цель проекта

Этот проект создан для:
- Демонстрации антипаттернов UX дизайна
- Обучения на примерах того, как **не** стоит делать
- Развлечения и показа абсурдности некоторых решений
- Легкого добавления новых примеров плохого UX
